# Q1. Electricity Bill Calculator

## Problem Statement

Write a Java program to calculate an electricity bill using the following slab rates:

| Units | Rate |
|-------|------|
| First 100 units | ₹5 per unit |
| Next 100 units | ₹6 per unit |
| Next 300 units | ₹7 per unit |
| Above 500 units | ₹10 per unit |
