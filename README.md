# Q1. Electricity Bill Calculator

## Problem Statement

Write a Java program to calculate an electricity bill using the following slab rates:

| Units | Rate |
|-------|------|
| First 100 units | ₹5 per unit |
| Next 100 units | ₹6 per unit |
| Next 300 units | ₹7 per unit |
| Above 500 units | ₹10 per unit |



Question 2: Water Bill Calculator

Write a Java program to calculate the water bill.

First 1000 liters → ₹2 per liter
Next 1000 liters → ₹3 per liter
Above 2000 liters → ₹5 per liter

Condition:

If the bill exceeds ₹6000, add 10% tax.
